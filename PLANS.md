- `fix-production-bug`

## 6. Технические наблюдения на будущее
- **Self-Healing Memory**: наблюдать за `lessons_learned.md`. Если файл начнет разрастаться до сотен багов, потребуется алгоритм его контекстного обрезания или саммаризации (например, через плагин DCP).
- **DCP Plugin**: параметры настроены на агрессивную компрессию (`contextLimit: 150000`, `nudgeFrequency: 10`). Следить за качеством сохраняемого контекста агентами.
- Windows path edge case: `apply_patch` может некорректно парсить абсолютные пути (`D:\...`) и давать ENOENT вида `...\\D`. До отдельного расследования используем для правок только инструменты `edit`/`write`.
