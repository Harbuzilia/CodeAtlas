## Что остаётся на тебя (не блокирует, но решать тебе)

1. **Нет remote/origin** — CI ни разу реально не гонялся на GitHub Actions (проверен только локально
   той же командой), `/pr` упадёт на preflight, релиз не прогнан end-to-end с реальным push тега.
   Тегов в репо нет вообще — первый `npm run release -- minor` создаст `v1.1.0` от текущего состояния.
2. **`registry.json`: placeholder `repository` URL** — заполни реальный URL после создания репо.
3. **Именование**: папка `Opencode1` vs `package.json` name `opencode-config` vs плейсхолдер URL —
   приведи к одному имени.
4. **Root `opencode.json` `permission.edit` globs** — на уровне *агентов* globs не работают
   (проверено на 1.18.18); на root-конфиге поведение не проверено. Поэтому НЕ удалял — только
   помечаю: возможно, ограничения на root-уровне тоже фиктивны. Проверь `opencode debug` перед
   доверием к ним.
5. **Node 20 (CI) vs Node 26 (локально)** — тесты совместимы с 20.11+ (`import.meta.dirname`),
   но CI реально проверит только после появления remote.
6. **Исторические записи CHANGELOG** содержат `file:///` абсолютные ссылки — трогать историю не стал.
7. **`PROJECT_GUIDE.md` §6 упоминает у docs-sync «(Change Log section)»** — такой секции в теле
   скилла нет; поправь формулировку при следующей правке скилла (не менял, чтобы не трогать тела
   скиллов вне согласованного скоупа).
