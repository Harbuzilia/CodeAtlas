# Code Review Skill

## Процесс ревью

### 1. Безопасность (КРИТИЧНО)
- [ ] SQL инъекции - используются параметризованные запросы?
- [ ] XSS - экранируется пользовательский ввод?
- [ ] Секреты - нет хардкода паролей/ключей?
- [ ] Валидация - проверяется весь внешний ввод?
- [ ] Авторизация - проверяются права доступа?

### 2. Производительность
- [ ] N+1 запросы - нет ли лишних обращений к БД?
- [ ] Async/await - используется для I/O операций?
- [ ] Кэширование - есть где нужно?
- [ ] Индексы - запросы оптимизированы?
- [ ] Memory leaks - ресурсы освобождаются?

### 3. Качество кода
- [ ] SOLID принципы соблюдены?
- [ ] DRY - нет дублирования?
- [ ] Naming - понятные имена переменных/функций?
- [ ] Комментарии - сложная логика объяснена?
- [ ] Error handling - ошибки обрабатываются корректно?

### 4. Тестируемость
- [ ] Код можно покрыть unit тестами?
- [ ] Зависимости инжектируются?
- [ ] Нет скрытых зависимостей от глобального состояния?

## Формат вывода

```
## 🔴 Критичные проблемы
[список с объяснением и fix]

## 🟡 Рекомендации
[список улучшений]

## 🟢 Хорошо
[что сделано правильно]

## Итог
[краткий вердикт: approve/request changes]
```
