# Performance Optimize Skill

## Процесс оптимизации

### 1. Измерить (до оптимизации!)
- Определить метрику (время, память, CPU)
- Получить baseline значения
- Найти bottleneck (не угадывать!)

### 2. Анализ
- Профилирование кода
- Анализ запросов к БД
- Проверка алгоритмической сложности

### 3. Оптимизация
- Одно изменение за раз
- Измерить после каждого изменения
- Документировать результат

## Типичные проблемы и решения

### База данных

#### N+1 запросы
```
❌ foreach (user in users) { user.Orders.Load(); }
✅ users.Include(u => u.Orders).ToList();
```

#### Отсутствие индексов
```sql
-- Проверить план запроса
EXPLAIN ANALYZE SELECT * FROM users WHERE email = '...';
-- Добавить индекс
CREATE INDEX idx_users_email ON users(email);
```

#### SELECT *
```
❌ SELECT * FROM users
✅ SELECT id, name, email FROM users
```

### Код

#### Лишние аллокации
```csharp
❌ string result = "";
   foreach (var s in items) result += s;
✅ var sb = new StringBuilder();
   foreach (var s in items) sb.Append(s);
```

#### Синхронный I/O
```csharp
❌ File.ReadAllText(path);
✅ await File.ReadAllTextAsync(path);
```

#### Лишние итерации
```csharp
❌ list.Where(x => x.Active).ToList().Count();
✅ list.Count(x => x.Active);
```

### Кэширование

#### Когда кэшировать
- Данные читаются часто, меняются редко
- Вычисление дорогое
- Допустима небольшая задержка обновления

#### Паттерны
```
Cache-Aside: проверь кэш → если нет, загрузи → положи в кэш
Write-Through: пиши в кэш и БД одновременно
Write-Behind: пиши в кэш, БД обновится асинхронно
```

## Чеклист

### Быстрые победы
- [ ] Добавить недостающие индексы
- [ ] Убрать N+1 запросы
- [ ] Включить кэширование
- [ ] Использовать async/await
- [ ] Убрать лишние SELECT *

### Глубокая оптимизация
- [ ] Профилирование CPU
- [ ] Анализ памяти (memory leaks)
- [ ] Оптимизация алгоритмов O(n²) → O(n log n)
- [ ] Connection pooling
- [ ] Batch операции вместо поштучных
