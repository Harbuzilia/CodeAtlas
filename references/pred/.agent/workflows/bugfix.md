# Bugfix Workflow

Быстрый workflow для исправления багов.

## Шаги

### 1. Понять проблему
// turbo
```prompt
Проанализируй описание бага: $ARGUMENTS

Определи:
- Симптомы (что происходит)
- Ожидаемое поведение
- Где искать (файлы, функции)
```

### 2. Найти причину
```prompt
Используя grep и read, найди:
1. Файл с проблемным кодом
2. Конкретное место (функция, строка)
3. Корневую причину бага

Покажи найденный код.
```

### 3. Написать регрессионный тест
```prompt
ПЕРЕД исправлением напиши тест, который:
1. Воспроизводит баг (сейчас должен падать)
2. Будет проходить после исправления

Это гарантирует, что баг не вернётся.
```

### 4. Исправить
```prompt
Исправь баг минимальными изменениями.

Правила:
- Не рефактори рядом стоящий код
- Только точечное исправление
- Сохрани обратную совместимость
```

### 5. Проверить тест
```bash
# Запусти тесты
npm test || dotnet test || pytest
```

### 6. Условие: тесты прошли?

Если тесты проходят:
```prompt
Отлично! Подготовь коммит:
fix: краткое описание исправления
```

Если тесты падают:
```prompt
Тесты всё ещё падают. Проанализируй вывод и попробуй снова.
Максимум 3 попытки, потом сообщи пользователю.
```

### 7. Коммит
// turbo
```bash
git add .
git commit -m "fix: $ARGUMENTS"
```

```
/bugfix NullReferenceException при сохранении пользователя
/bugfix кнопка Login не работает на мобильных
/bugfix API возвращает 500 при пустом email
```
