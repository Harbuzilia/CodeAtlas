# Plan Command | Команда /plan

## Назначение
Сформировать понятный план выполнения задачи с минимальным количеством вопросов.

## Вход
- `/plan <краткое описание>`
- `/plan` без аргументов — ассистент задает 1-2 уточняющих вопроса

## Автоматический режим
1. Прочитать `context/core/config/paths.json`, определить `<context_root>`, затем прочитать `<context_root>/navigation.md` и релевантные стандарты.
2. Определить тип: feature или fix (по формулировке запроса).
3. Выбрать режим:
   - Быстрый — по умолчанию (3-6 шагов)
   - Полный — если риск высок или затронуто 4+ файла
4. Сформировать план: инкременты, критерии приемки, тесты, риски.
5. Если нужны правки кода — запросить подтверждение перед изменениями.

## Выход (формат)
```
Короткое резюме

Инкременты:
1) ...
2) ...

Критерии приемки:
- Given/When/Then

План тестирования:
- ...

Риски и смягчение:
- ...
```

## Пример
```
/plan добавить фильтры в список заказов
```
