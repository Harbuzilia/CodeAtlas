# Test Command | Команда /test

## Назначение
Быстро сформировать тест-план и выполнить безопасные проверки без лишних вопросов.

## Вход
- `/test <область/фича>`
- `/test` без аргументов — определить область по изменениям (git diff) или по контексту

## Автоматический режим
1. Определить область тестирования (по аргументам или diff).
2. Сформировать тест-план: unit → integration → E2E, где уместно.
3. Если нужно писать тесты — сначала получить подтверждение тест-плана.
4. Запускать только безопасные проверки (lint/unit), а потенциально разрушительные действия — по подтверждению.

## Выход (формат)
```
Короткое резюме

План тестирования:
- Unit: ...
- Integration: ...
- E2E/UI: ...

Команды запуска (если известны):
- ...

Риски:
- ...
```

## Пример
```
/test оформление заказа
```
