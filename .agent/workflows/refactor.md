# Deep Refactoring Workflow

Систематический рефакторинг с сохранением функциональности.

## Шаги

### 1. Анализ текущего состояния
```prompt
Проанализируй код: $ARGUMENTS

Найди проблемы:
- [ ] Code smells (длинные методы, god classes)
- [ ] Дублирование кода
- [ ] Нарушения SOLID
- [ ] Сложная вложенность
- [ ] Magic numbers/strings
- [ ] Отсутствие типизации

Сохрани анализ в `.tmp/refactoring-analysis.md`
```

### 2. Проверить тесты ДО рефакторинга
```bash
# Убедимся что тесты проходят ДО изменений
npm test || dotnet test || pytest
```

Условие: Если тесты падают → СТОП, сначала исправь

### 3. Создать план рефакторинга
```prompt
На основе анализа создай план:

Формат `.tmp/refactoring-plan.md`:
```markdown
# План рефакторинга

## Приоритет 1 (критично)
- [ ] Описание изменения 1
- [ ] Описание изменения 2

## Приоритет 2 (важно)
- [ ] ...

## Приоритет 3 (улучшения)
- [ ] ...
```

Покажи план пользователю для одобрения.
```

### 4. Итерация рефакторинга (цикл)

Повторять пока есть незавершённые пункты:

#### 4.1 Читаем план
// turbo
```bash
cat .tmp/refactoring-plan.md
```

#### 4.2 Выполняем следующий пункт
```prompt
Найди первый незавершённый пункт `- [ ]` в плане.

Выполни рефакторинг:
1. Сделай минимальное атомарное изменение
2. Сохрани функциональность
3. Отметь пункт как `- [x]`
```

#### 4.3 Запускаем тесты
```bash
npm test || dotnet test || pytest
```

#### 4.4 Условие: тесты прошли?

Если да: переходи к следующему пункту

Если нет: 
```prompt
Тесты упали после рефакторинга. 
Откати последнее изменение и попробуй другой подход.
```

#### 4.5 Микро-коммит
// turbo
```bash
git add .
git commit -m "refactor: [описание изменения]"
```

### 5. Проверка: все пункты выполнены?

```prompt
Прочитай `.tmp/refactoring-plan.md`

Если остались `- [ ]` → вернись к шагу 4
Если все `- [x]` → переходи к шагу 6
```

### 6. Финальная проверка
```bash
# Полный прогон тестов
npm test || dotnet test || pytest

# Проверка типов (если применимо)
tsc --noEmit || mypy . || true
```

### 7. Итоговый отчёт
```prompt
Создай `.tmp/refactoring-summary.md`:

# Отчёт о рефакторинге

## Что было сделано
- Изменение 1
- Изменение 2
...

## Метрики
- Файлов изменено: X
- Строк удалено: Y
- Строк добавлено: Z

## Улучшения
- Уменьшена сложность
- Удалено дублирование
...
```

### 8. Очистка
// turbo
```bash
rm -f .tmp/refactoring-analysis.md
rm -f .tmp/refactoring-plan.md
# Оставляем summary для истории
```
