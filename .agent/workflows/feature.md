# Feature Full-Cycle Workflow

Автоматический workflow для создания новой функциональности.

## Шаги

### 1. Анализ требований
// turbo
```prompt
Проанализируй запрос: $ARGUMENTS

Определи:
- Что именно нужно сделать
- Какие файлы затронуты
- Какой язык/фреймворк
- Примерная сложность (simple/medium/complex)

Выведи краткий анализ.
```

### 2. Декомпозиция на подзадачи
```prompt
На основе анализа, разбей задачу на атомарные подзадачи.

Формат:
- [ ] Подзадача 1 (файл: X, тип: create/modify)
- [ ] Подзадача 2 (файл: Y, тип: create/modify)
...

Сохрани в `.tmp/current-task.md`
```

### 3. Загрузка контекста
// turbo
```bash
# Загружаем стандарты кода
cat context/core/standards/code.md
```

### 4. Реализация (цикл)
```prompt
Прочитай `.tmp/current-task.md`

Для каждой незавершённой подзадачи:
1. Реализуй её согласно стандартам
2. Отметь как [x] выполненную
3. Перейди к следующей

Остановись когда все подзадачи выполнены.
```

### 5. Написание тестов
```prompt
Для каждого созданного/изменённого файла:
1. Создай unit-тесты (Arrange-Act-Assert)
2. Покрой позитивный и негативный сценарии
3. Используй моки для внешних зависимостей

Следуй стандартам из context/core/standards/tests.md
```

### 6. Запуск тестов
```bash
# Определи тип проекта и запусти тесты
if [ -f "*.csproj" ]; then
  dotnet test
elif [ -f "package.json" ]; then
  npm test
elif [ -f "pyproject.toml" ] || [ -f "pytest.ini" ]; then
  pytest
fi
```

### 7. Code Review (self)
```prompt
Проведи self-review созданного кода:

Чеклист:
- [ ] SOLID принципы соблюдены
- [ ] Нет SQL injection / XSS
- [ ] Async/await корректен
- [ ] Нет дублирования кода
- [ ] Есть документация для публичных API

Если есть проблемы — исправь и повтори шаг 4.
```

### 8. Коммит
```bash
git add .
git status
```

```prompt
На основе git diff создай commit message:
- Формат: type: description
- Используй conventional commits

Выполни коммит.
```

### 9. Очистка
// turbo
```bash
rm -f .tmp/current-task.md
```

---

## Условия выхода

-  Успех: Все тесты проходят, код закоммичен
-  Провал: Тесты падают 3 раза подряд → остановись и сообщи пользователю
-  Пауза: Сложность > estimated → запроси уточнения
