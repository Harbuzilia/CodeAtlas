# Budget Command | Команда /budget

## Назначение
Предоставить подробную финансовую и токен-аналитику текущей сессии: суммарные входные/выходные токены, распределение по субагентам (`coder`, `planner`, `tester`, `reviewer`) и расчет стоимости по тарифам моделей из каталога `opencode.json` (тарифы привязаны к фактической модели каждого агента из пресета `/presets`).

## Вход
- `/budget` — вывод текущего отчета о потреблении ресурсов
- `/budget limit <число>` — установка локального порога предупреждения

## Пример вывода
```
====================================================
      💰 OPENCODE TOKEN & COST BUDGET TELEMETRY     
====================================================

📊 Распределение токенов по агентам:
- coder:       18,450 tokens (Input: 14,200 | Output: 4,250)
- planner:      4,120 tokens (Input:  3,200 | Output:   920)
- reviewer:     5,300 tokens (Input:  4,800 | Output:   500)
- contextscout: 2,100 tokens (Input:  1,900 | Output:   200)

📈 Всего токенов: 29,970 tokens
💵 Ориентировочная стоимость: ~$0.045 USD
🛡️ Статус бюджета: В пределах нормы (< 200,000 tokens)
====================================================
```
