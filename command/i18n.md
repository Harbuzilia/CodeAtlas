# i18n Command | Команда /i18n

## Назначение
Проверить проект на наличие пропущенных переводов между словарями локализаций (`ru.json`, `en.json`), найти хардкодные строки в шаблонах/компонентах и помочь сгенерировать недостающие переводы.

## Вход
- `/i18n <модуль/локаль>` (например, `/i18n check` или `/i18n extract src/components/Auth`)
- `/i18n` без аргументов — полный аудит всех локалей проекта

## Автоматический режим
1. Найти директорию с переводами (`locales/`, `messages/`, `i18n/`, `Resources/`).
2. Загрузить навык `i18n-localization`.
3. Сравнить наборы ключей между всеми языковыми файлами:
   - Выявить ключи, присутствующие в `ru`, но отсутствующие в `en` (и наоборот).
4. Просканировать UI-файлы (JSX, TSX, HTML) на наличие строковых литералов без вызова `t(...)`.
5. Сформировать отчет с готовыми дополнениями для словарей.
