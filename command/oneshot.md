# Oneshot Command | Команда /oneshot

## Назначение
Явно включить one-shot режим для ТЕКУЩЕЙ задачи: оркестратор исполняет полную цепочку выбранного functional mode под ключ (plan → implement → review → test → docs, по карте one-shot в `agents/openagent.md`) без промежуточных остановок.

## Вход
- `/oneshot <описание задачи>` — классифицировать mode и исполнить one-shot-цепочку
- Эквиваленты-триггеры: `one-shot: on` в тексте задачи, «сделай под ключ»

## Поведение
1. Без описания задачи — спросить её через question tool.
2. Делегировать оркестратору с явной меткой one-shot (цепочка и её правила описаны в `agents/openagent.md`, блок one_shot_mode).
3. Отключение: `one-shot: off` или новая задача без триггеров — режим по умолчанию OFF.
