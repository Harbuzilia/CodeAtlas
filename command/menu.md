# Menu Command | Команда /menu

> Этот файл сгенерирован автоматически (`npm run menu:gen`). Ручные правки будут перезаписаны; валидатор реестра проверяет свежесть.

## Назначение
Показать карту возможностей системы. Режимы переключать не нужно: `openagent` — единственный primary-оркестратор, он сам классифицирует запрос и молча делегирует профильному субагенту.

## Поведение
1) Выведи карту (формат ниже) и спроси задачу.
2) Классифицируй ответ пользователя как обычный запрос и маршрутизируй по `functional_modes` / `delegation_rules`.
3) `/menu` можно вызвать повторно.

## Формат ответа
```
## Карта системы

Просто опишите задачу — оркестратор сам выберет маршрут:
- Новая фича / код -> coder
- Баг / падение -> debugger
- Тесты -> tester
- Ревью / аудит / безопасность -> contextscout + reviewer
- План / декомпозиция -> planner
- Архитектура / ADR / C4 -> architect
- Docker / CI/CD / деплой -> devops
- Документация -> docwriter
- Визуальные UI тесты -> uitester

Slash-команды (23):
- `/arch` — Автоматическая генерация интерактивных C4 Container и Component архитектурных диаграмм в Mermaid
- `/bootstrap` — Однокликовый бутстраппинг боевой инфраструктуры (Multi-stage Docker, Compose, Telemetry, Health endpoints)
- `/budget` — Аналитика расхода токенов по субагентам, расчет ориентировочной стоимости в USD и контроль бюджета
- `/build-context-system` — Интерактивный конструктор системы контекста для генерации полной .opencode архитектуры под домен пользователя
- `/commit` — Умные conventional commits с автоматическим анализом изменений
- `/conflict` — Автоматический поиск маркеров конфликта Git, семантический анализ (ours vs theirs) и интеллектуальное разрешение
- `/docgen` — Автоматическая генерация Markdown-документации модулей из AST с сигнатурами типов и Mermaid диаграммами
- `/doctor` — Комплексная 360° диагностика окружения агентов, валидности манифестов, путей и целостности ссылок
- `/heal` — Автономный цикл самовосстановления с песочницей, авто-исправлением ошибок через debugger и безопасным авто-откатом
- `/i18n` — Проверка синхронизации переводов i18n, выявление отсутствующих ключей и захардкоженных строк
- `/infra` — Быстрая генерация инфраструктурных конфигов (Docker, Compose, Nginx, CI/CD, K8s)
- `/matrix` — Интерактивная карта мультиагентной системы, бюджеты шагов, права на файлы и реестр 37 навыков
- `/modernize` — Автоматическая модернизация легаси-кода на современные стандарты (ESM, async/await, React 19)
- `/optimize` — Быстрый аудит производительности, поиск N+1 запросов, узких мест и тяжелых зависимостей
- `/oracle` — Предиктивный AI-анализ вероятности дефектов и автогенерация упреждающих защитных гардов
- `/plan` — Декомпозиция задач по INVEST с сохранением чек-листа в .opencode/task_state.md
- `/pr` — Автономный конвейер: валидация, Conventional Commit, push в remote и создание Pull Request через GitHub CLI
- `/prompt-engineering/prompt-optimizer` — Продвинутый оптимизатор промптов: исследовательские паттерны + токен-эффективность + 100% сохранение смысла
- `/prompt` — Генератор высокоплотных системных промптов для внешних LLM, ботов и автономных агентов
- `/release` — Автоматическая подготовка релиза SemVer, генерация changelog из Conventional Commits и создание Git-тега
- `/review` — Профессиональное код-ревью с фокусом на безопасность (SAST), качество и diff-исправления
- `/synthesize` — Сквозной автономный синтез фичи под ключ из текстового запроса или файла спецификации
- `/test` — Автоматическая генерация и запуск тестов (TDD, Unit, Integration, E2E Playwright)

Полный запуск цепочки без остановок: добавьте `one-shot: on` или `сделай под ключ`.
```
