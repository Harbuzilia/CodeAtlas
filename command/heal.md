# Heal Command | Команда /heal

## Назначение
Запустить полностью изолированный и безопасный цикл самовосстановления:
1. Создание снимка репозитория (Git snapshot).
2. Запуск компиляции, линтинга, типов и тестов.
3. При обнаружении ошибок — передача AST stack-trace агенту `debugger` для применения умных фиксов (до 3 итераций).
4. **Auto-Rollback**: если ошибка не поддается автоматическому исправлению, кодовая база мгновенно и чисто откатывается в исходное состояние с 0 остаточных багов.

## Вход
- `/heal` — полный запуск цикла проверки и починки
- `/heal <файл/тест>` — прицельное самовосстановление конкретного модуля

## Пример вывода
```
====================================================
     👑 OPENCODE AUTONOMOUS SELF-HEALING SANDBOX     
====================================================

1. 📸 Clean Snapshot created (Safety checkpoint saved).
2. 🔍 Running Quality Gates & Verification...
   - Typecheck: ✅ PASS
   - Unit Tests: ✅ PASS
   - Linting:    ✅ PASS
   - Security:   ✅ PASS

🎉 Project is 100% healthy! No self-healing interventions required.
====================================================
```
