# Review Command | Команда /review

## Назначение
Провести понятное и точное ревью с приоритизацией по рискам.

## Вход
- `/review <область>`
- `/review` без аргументов — ревью по текущему diff

## Автоматический режим
1. Собрать контекст изменений (git diff / список файлов).
2. Проверить критичные риски: безопасность, корректность, совместимость.
3. Отдельно оценить тесты и наблюдаемость.
4. Сформировать вывод: критично → важно → миноры → что хорошо.

## Выход (формат)
```
Критичные проблемы:
- ...

Важные рекомендации:
- ...

Миноры/ниты:
- ...

Что хорошо:
- ...

Вердикт: approve | request changes | needs discussion
```

## Пример
```
/review авторизация
```
