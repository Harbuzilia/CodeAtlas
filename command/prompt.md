# Prompt Command | Команда /prompt

## Назначение
Преобразовать любую пользовательскую формулировку или задачу в профессиональный, готовый к копированию системный промпт с XML-структурой, Few-Shot примерами и защитой от галлюцинаций.

## Вход
- `/prompt <описание агента/задачи/бота>`
- `/prompt` без аргументов — интерактивный диалог для генерации промпта

## Автоматический режим
1. Загрузить навык `prompt-engineering-advanced`.
2. Определить целевую роль, контекст, граничные случаи и форматы ответов.
3. Сформировать структурированный промпт с XML-тегами (`<role>`, `<context>`, `<instructions>`, `<constraints>`, `<output_format>`).
4. Вывести готовый промпт в блоке кода.
