# Verification Before Completion Skill

> «Готово» — это доказательство, а не ощущение. Каждое заявление проверяется свежим выводом.
> Адаптировано из ядра obra/superpowers (MIT).

## Зачем

«Сделал» без прогона = баг в проде + потерянное доверие. Верификация стоит минуты; откат — часы. Правило: любое утверждение о результате должно быть воспроизводимо.

## Правила (обязательные)

1. **Каждое утверждение = свежая команда.** «Тесты зелёные» → процитируй вывод последнего прогона с числом тестов. «Сборка проходит» → приведи вывод build/typecheck. «Файл обновлён» → покажи, что именно изменилось (`git diff`).
2. **Никаких «должно работать».** Не прогнал — не заявляй. Если прогнать нельзя (нет окружения) — скажи прямо: «не верифицировано, потому что X».
3. **Несовпадения объявляются явно.** Ожидал 5 тестов, прошло 4 skipped/1 filtered — так и напиши. Скрытая оговорка = ложное «готово».
4. **Верифицируй ЗАЯВЛЕННЫЙ результат, не соседний.** Юзер просил «кнопка сохраняет форму» — проверь сценарий кнопки, а не только линтер.
5. **Возврат результата = мини-отчёт**: Summary → What I ran (команды + вывод) → What I did NOT run и почему → Risks.

## Уровни верификации (минимум по типу задачи)

| Тип задачи | Минимальная верификация |
|------------|------------------------|
| Код-фикс | Упавший репро + затронутые тесты |
| Новая фича | Юнит-тесты нового кода + build/typecheck + smoke сценария |
| Рефакторинг | Полный suite 1 раз + diff показывает только намеренные изменения |
| Конфиг/инфра | Синтаксис-чек + применение на живом объекте (или dry-run) |
| Доки/текст | Читается целиком, ссылки живы, числа сверены с источником |

## Анти-паттерны (STOP-сигналы)

- «Всё работает» без единой процитированной команды.
- Прогон старый: код менялся ПОСЛЕ последнего прогона.
- Тесты «и так зелёные были» — код под ними уже другой.
- Спрятанное «кроме...» в конце отчёта.

## Чеклист перед любым «готово»

- [ ] Прогнано ровно то, что заявлено (не соседнее)
- [ ] Вывод команд процитирован с числами
- [ ] Непроверенное явно помечено «не верифицировано: причина»
- [ ] Риски и откат названы
