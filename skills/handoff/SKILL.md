# Handoff Skill

> Передача контекста между сессиями без потери. Адаптировано из mattpocock/skills (MIT).
> Вызывается пользователем («сдай смену», «handoff», «передай контекст следующей сессии») или в конце длинной задачи.

## Зачем

Свежая сессия начинает с нуля и переоткрывает уже найденное. Handoff-документ — это сжатая смена: 30 секунд чтения вместо 20 минут rediscovery.

## Правила

1. **Файл**: `.opencode/handoff/<ГГГГ-ММ-ДД>-<slug>.md` (runtime-state, не в git).
2. **Структура**:
   - `Context` — задача одной строкой + текущий статус (done / in-progress / blocked);
   - `Done` — что реально сделано (ссылки на коммиты/PR, не пересказ);
   - `Left` — что осталось, по приоритету, с «первым следующим шагом»;
   - `Artifacts` — пути к спекам/планам/ADR/issue/диффам (ссылками, НЕ копией контента);
   - `Suggested skills` — какие скиллы грузить следующей сессии (`skill({ name: "..." })`);
   - `Pitfalls` — грабли, на которые уже наступили (1-5 строк).
3. **Не дублируй** содержимое артефактов (спеки, планы, ADR, коммиты) — только путь/URL; документ ≤60 строк.
4. **Секреты редактируй**: API-ключи, пароли, PII — не включай вообще; при необходимости — «см. .env (имя переменной)».
5. **Аргумент пользователя** = фокус следующей сессии — подстрой разделы под него (например, «следующая сессия — деплой» → раздуй Left/Artifacts про деплой).
6. Если есть живые `progress.md`/`findings.md` — их итоги сверни в Done/Left, а файлы упомяни в Artifacts.
