# Pattern Vocabulary — словарь композиционных приёмов

Дочитывать при: поиске hero-концепции, навигационного приёма, scroll-идеи, когда «не знаю, из чего выбрать». Название → известный паттерн, реализуемый стеком проекта.

## Hero
- **Asymmetric Split** — текст одна сторона, воздух другая, почти-постер.
- **Video / Media Mask** — типографика как маска поверх видео-фона.
- **Kinetic-Type Hero** — анимируемая типографика как главный визуал.
- **Curtain-Reveal** — hero раскрывается при скролле как занавес.
- **Scroll-Pinned Hero** — hero пинится, контент уезжает поверх.

## Навигация и меню
- **Mac OS Dock Magnification** — краевая навигация, иконки плавно скейлятся при hover.
- **Magnetic Button** — кнопка тянется к курсору.
- **Gooey Menu** — подпункты отделяются как вязкая жидкость.
- **Dynamic Island** — морфящаяся pill для статуса/алертов.
- **Contextual Radial Menu** — круговое меню в точке клика.
- **Floating Speed Dial** — FAB, раскрывающийся в дугу вторичных действий.
- **Mega Menu Reveal** — полноэкранный dropdown со stagger-fade контентом.

## Layout и сетки
- **Bento Grid** — асимметричная группировка плиток (Apple Control Center).
- **Masonry** — стаггерed-сетка без фиксированной высоты строк.
- **Chroma Grid** — бордеры/плитки с тихими анимируемыми градиентами.
- **Split-Screen Scroll** — две половины едут в противоположные стороны.
- **Sticky-Stack Sections** — секции пинятся и складываются при скролле.

## Карточки и контейнеры
- **Parallax Tilt Card** — 3D-наклон за курсором.
- **Spotlight Border Card** — бордеры подсвечиваются под курсором.
- **Glassmorphism Panel** — матовое стекло с внутренней рефракцией (точечно, не дефолт).
- **Holographic Foil Card** — радужный foil-сдвиг при hover.
- **Tinder Swipe Stack** — физический стек карточек со swipe-away.
- **Morphing Modal** — кнопка разворачивается в собственный диалог.

## Scroll-анимации
- **Sticky Scroll Stack** — карточки липнут и физически складываются (скелет в animation-patterns.md).
- **Horizontal Scroll Hijack** — вертикальный скролл → горизонтальный пан (скелет там же).
- **Locomotive / Sequence Scroll** — видео/3D-секвенция привязана к скроллбару.
- **Zoom Parallax** — центральное фоновое изображение зумится при скролле.
- **Scroll Progress Path** — SVG-линия дорисовывается по скроллу.
- **Liquid Swipe Transition** — страничный переход как вязкая жидкость.

## Галереи и медиа
- **Dome Gallery** — 3D панорамная галерея.
- **Coverflow Carousel** — 3D-карусель со скошенными краями.
- **Drag-to-Pan Grid** — безграничный draggable canvas.
- **Accordion Image Slider** — узкие полосы, раскрывающиеся при hover.
- **Hover Image Trail** — за курсором тянется шлейф изображений.
- **Glitch Effect Image** — RGB-channel shift при hover.

## Типографика и текст
- **Kinetic Marquee** — бегущие текстовые ленты, реверс при скролле.
- **Text Mask Reveal** — крупная типографика как прозрачное окно в видео.
- **Text Scramble** — Matrix-декодирование при load/hover.
- **Circular Text Path** — текст по вращающейся окружности.
- **Gradient Stroke Animation** — контурный текст с бегущим градиентом.
- **Kinetic Typography Grid** — буквы уворачиваются от курсора.

## Микро-интеракции
- **Particle Explosion Button** — CTA рассыпается в частицы при success.
- **Liquid Pull-to-Refresh** — индикатор перезагрузки как отрывающаяся капля.
- **Skeleton Shimmer** — световой блик по плейсхолдерам загрузки.
- **Directional Hover-Aware Button** — заливка входит со стороны курсора.
- **Ripple Click** — волна из точки клика.
- **Animated SVG Line Drawing** — векторы рисуют себя в реальном времени.
- **Mesh Gradient Background** — органические lava-lamp blobs.
- **Lens Blur Depth** — фон блюрится, фокус на переднем действии.
