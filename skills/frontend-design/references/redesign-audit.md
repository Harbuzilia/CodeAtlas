# Redesign Protocol — аудит перед изменениями

Дочитывать при: задаче «редизайн», «освежить», «modern-design» на существующем продукте. Misclassification режима — главный источник плохих редизайнов.

## Определение режима (первое действие)
- **Greenfield** — нет существующего сайта или одобрен полный overhaul. Диски из пресетов SKILL.md.
- **Redesign–Preserve** — модернизация без ломки бренда. Сначала аудит, извлечь brand-токены, эволюция.
- **Redesign–Overhaul** — новый визуальный язык поверх существующего контента. Как greenfield для визуала; контент и IA сохранить.

Неоднозначно → спросить ОДИН раз: «Сохраняем существующий бренд или начинаем визуально с нуля?»

## Аудит до любых правок (документировать)
- **Brand tokens** — primary/accent цвета, type stack, лого, радиусы.
- **Information architecture** — дерево страниц, primary nav, ключевые conversion-пути.
- **Контент-блоки** — что есть, что работает, что filler.
- **Что сохранить** — фирменные интеракции, узнаваемый hero, голос копии.
- **Что выбросить** — AI-slop tells, сломанные layout'ы, мёртвые ссылки, generic-сток, perf-ловушки.
- **Dial-reading существующего сайта** — вывести текущие VARIANCE/MOTION/DENSITY. Это стартовая точка, не пресет.
- **SEO baseline** — ранжирующиеся страницы, meta titles, structured data, OG-карточки. **SEO-миграция — риск №1 редизайна.**

## Правила сохранения
- **IA не менять** без запроса. Slug'и страниц, anchor-ID, primary nav labels — стабильны (SEO + мышечная память).
- **Brand-цвета извлечь до применения цветовых правил.** Бренд, который уже purple, остаётся purple — действует brand-override.
- **Голос копии сохранить** без явного запроса на рерайт. Визуальная модернизация ≠ рерайт контента.
- **Не регрессировать a11y:** focus-стейты, alt-тексты, keyboard nav, контраст — не ухудшать.
- **Уважать аналитику:** не переименовывать кнопки, поля форм, ID секций, от которых зависит трекинг.

## Рычаги модернизации (по приоритету — стоп, когда бриф закрыт)
1. **Типографика** — наибольший визуальный лифт на единицу риска.
2. **Отступы и ритм** — section padding, вертикальный ритм.
3. **Цветовая рекалибровка** — десатурация, унификация нейтральных, акцент бренда сохранить.
4. **Motion-слой** — микроинтеракции уровня MOTION_INTENSITY в существующие компоненты.
5. **Рекомпозиция hero и ключевых секций** — словарь из pattern-vocabulary.md.
6. **Полная замена блока** — только если существующий не спасти.

## Дерево решений: эволюция vs полный редизайн
- IA, контент, SEO в порядке → **точечная эволюция** (рычаги 1–4). ~70% ценности за ~40% риска.
- Визуальный долг структурный (сломанная IA, нет дизайн-системы, сломанный mobile) → **полный редизайн** со строгим сохранением контента.
- Меняется сам бренд → **greenfield**.

## Что никогда не менять молча (только с явным одобрением)
- URL-структура / slug'и роутов.
- Labels primary nav.
- Имена аналитических событий, ID форм.
- Brand-цвет и лого.
