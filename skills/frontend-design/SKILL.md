# Frontend Design (Anti-Slop)

LLM-дефолт = шаблон: AI-purple градиенты, Inter, 3 одинаковые карточки, центрированный герой. Каждое правило ниже — контекстное, сначала прочитай бриф, потом применяй.

## 0. Design Read (обязательно первым)

Перед кодом — одна строка: **«Читаю как: \<тип страницы> для \<аудитории>, вайб \<X>, система \<Y>».**
Пример: *«B2B SaaS лендинг для тех. байеров, Linear-style минимализм, Tailwind + Geist + сдержанная анимация»*.
Сигналы: vibe-слова юзера, референсы, аудитория, существующий бренд. Неясно и вилка реальна — задай ОДИН вопрос. Иначе не спрашивай.

## 1. Три диска (1-10)

| Диск | 1 | 10 |
|---|---|---|
| DESIGN_VARIANCE | строгая симметрия | арт-хаос |
| MOTION_INTENSITY | статика | кинематограф |
| VISUAL_DENSITY | галерея/воздух | кокпит/данные |

Пресеты: SaaS-лендинг 7/6/4 · агентство 9/8/3 · премиум-consumer 7/6/3 · портфолио дев 6/5/4 · паблик-сектор/trust 3/2/5 · редакционный 6/4/3. Redesign-preserve: матч существующего.
Продуктовый UI (дашборд/админка/CRM): 3/2/8 — плотность и предсказуемость важнее «вау». Десктоп-приложения: 2-4/1-3/5-8 — платформенные конвенции побеждают авторский стиль.

## 2. Система или эстетика

**Реальная система** — ставь официальный пакет, не перерисовывай CSS руками: Fluent (Microsoft), Material 3 (Google), Carbon (IBM), Polaris (Shopify), Primer (GitHub), GOV.UK/USWDS (госсектор), shadcn/ui (владеешь кодом — но НИКОГДА не в дефолтном виде). Одна система на проект, не мешать.
**Эстетика** (glass, bento, brutalism, editorial, dark-tech, kinetic type) — нативный CSS + Tailwind v4, честно помечай заимствование.

## 3. Анти-дефолты (жёсткие баны)

- **Inter — не по умолчанию.** Бери Geist, Satoshi, Cabinet Grotesk, PP Neue Montreal. Inter только если Linear-style/trust-бриф.
- **Serif — НЕ дефолт для «креатива».** Только editorial/luxury/heritage, с аргументацией. Fraunces и Instrument Serif — забанены как дефолт. Эмфаза в заголовке — italic/bold ТОГО ЖЕ шрифта, не вставка чужого serif.
- **AI-purple/blue glow забанен.** Макс 1 акцентный цвет, насыщенность < 80%. Акцент один на всю страницу (CTA, бейджи — тот же). Нейтрали: Zinc/Slate/Stone. Pure black `#000` запрещён — off-black/charcoal.
- **Premium-consumer:** НЕ beige+brass+espresso (крем `#f5f1ea`, латунь `#b08947`) — это LLM-клише №1. Альтернативы: cold luxury (chrome+smoke), forest+bone, cobalt+cream, olive+brick, монохром + один яркий акцент.
- **3 одинаковые карточки в ряд — бан.** Zig-zag max 2 подряд, дальше другая layout-семья. Мин 4 разных layout-семьи на страницу.
- **Eyebrow (small-caps лейбл над заголовком): макс 1 на 3 секции.** Заголовок сам достаточен.
- **Scroll-cues, полосы «BRAND. MOTION. SPATIAL.», локаль/погода в футере, версии «v1.4.2» на маркетинге, фейковые скриншоты из div'ов, «John Doe», «99.99%» — всё бан.** Имена/данные — реалистичные.

## 4. Layout hard-rules

- Герой целиком в viewport: headline ≤ 2 строк, подтекст ≤ 20 слов, CTA виден без скролла, top-padding ≤ `pt-24`, текста max 4 элемента (eyebrow|brand, H1, подтекст, CTA). Никаких таглайнов под CTA и логотипов-клиентов ВНУТРИ героя (ниже — отдельной секцией).
- Навигация: одна строка, высота ≤ 80px. CTA-текст в одну строку, ≤ 3 слов. Один интент CTA = одна формулировка на всю страницу.
- Bento: ячеек ровно столько, сколько контента; ≥2 ячейки с реальной визуальной вариацией (image/gradient/pattern), не white-on-white.
- `min-h-[100dvh]`, не `h-screen`. Grid, не flex-проценты. Тень под цвет фона, не чёрная.
- Кнопки/форма: контраст ≥ WCAG AA 4.5:1, плейсхолдер ≠ label, label над инпутом.
- Консистентность радиусов: одна система скруглений на страницу.

## 5. Motion

Motion (motion/react), не GSAP-by-default. `useMotionValue`/`useScroll`/`IntersectionObserver`, НЕ scroll-listeners и не useState для scroll/мыши. `prefers-reduced-motion` обязателен. Анимация = иерархия/фидбек/storytelling, не «для красоты».

## 6. Иконки и эмодзи

Одна библиотека на проект: Phosphor / HugeIcons / Radix / Tabler (Lucide — по запросу). Свои SVG-иконки не рисовать. Эмодзи в UI — только по явной просьбе.

## 7. Copywriting

Активный залог, конкретика («Save changes», не «Submit»). Ошибки — что случилось и как чинить, без извинений. Пустые состояния — приглашение к действию. Слова — навигация, не декор.

## 8. Продуктовый UI (дашборды, таблицы, формы, CRM)

- Здесь anti-slop = **плотность и предсказуемость**, не арт. Пользователь работает 8 часов: consistency > выразительность.
- Дизайн-система обязательна: shadcn/ui / Carbon / Fluent / Ant Design — одна, не самопал. Кастомизация токенов, не дефолтный вид.
- Таблицы: строка 40-48px, зебра ИЛИ divide (не оба), sticky-header при > 20 строк, числа — tabular-nums и правое выравнивание.
- Формы: label над инпутом, ошибки под инпутом, группировка связанных полей, primary-кнопка одна на форму.
- Пустые/загрузочные/ошибочные состояния — для КАЖДОГО списка и таблицы, не только happy path.
- Навигация: sidebar ≤ 240px или topbar, активный пункт явно подсвечен. Breadcrumbs при глубине > 2.
- Никаких hero-паттернов: гигантская типографика, eyebrow, «воздух» — это для маркетинга, не для рабочего инструмента.

## 9. Десктоп (WPF / WinUI / MAUI) и мобильные

- **Следуй платформенному HIG, не изобретай:** WinUI 3 / Fluent Design для Windows (Segoe UI Variable, Mica/Acrylic точечно, стандартные отступы 4/8/12/16/20/24, высота контролов 32px). macOS — SF Pro, vibrancy, конвенции Apple HIG. Кросс-платформа (MAUI/Flutter) — Material 3 как база.
- Десктоп-приложение ≠ сайт: нет hero-секций, нет маркетинговой типографики, окно имеет chrome, всё доступно с клавиатуры (Tab-ордер, focus visuals, accelerator keys).
- Свои контролы — только поверх стандартных стилей, не «с нуля»: кастомная кнопка без focus-rectangle и keyboard states = сломанный UI.
- Тёмная/светлая темы через ThemeResource/динамические ресурсы, не хардкод цветов.
- DPI-масштабирование: никаких фиксированных пиксельных размеров шрифтов/отступов вне сетки.
- Мобильные: touch-target ≥ 44x44pt, safe-area insets, жесты не конфликтуют с системными (edge-swipe).
- Анимации короткие (≤ 250ms) и функциональные (смена состояния), не декоративные — десктоп про скорость работы.
