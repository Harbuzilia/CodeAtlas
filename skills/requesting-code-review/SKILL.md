# Requesting Code Review Skill

> Ревью дешёвое, когда подготовлено. Дорогое — когда ревьюер сам разбирается, что ты сделал.
> Адаптировано из ядра obra/superpowers (MIT).

## Зачем

«Глянь плиз» вынуждает ревьюера восстановить контекст из диффа — и он находит не баги, а непонимание. Подготовленный запрос фокусирует ревью на рисках; дисциплина ответов не даёт критичному пройти мимо.

## Запрос на ревью (что приложить)

1. **Дифф минимален**: ничего постороннего (рефакторинг/форматирование — отдельным PR или отдельной секцией с пометкой).
2. **Контекст одной строкой**: что менялось и ЗАЧЕМ (ссылка на issue/требование).
3. **Что уже проверено**: команды + вывод (тесты, build) — ревьюер не ищет то, что ты уже доказал.
4. **Зоны риска — явно**: «не уверен в Х, посмотри особенно Y» — направляй внимание, а не надейся.
5. **Размер**: >400 строк диффа — дели на логические PR; огромный дифф = поверхностное ревью.

## Приём результата (дисциплина ответов)

- Каждое замечание получает один из трёх ответов:
  - **fixed** — исправлено (ссылка на коммит/строку);
  - **согласен, отдельной задачей** — завёл follow-up (номер);
  - **не согласен — аргумент**: технический контраргумент + данные, не мнение.
- Группируй по severity, отвечай на critical/blocker ПЕРВЫМИ.
- **Critical/blocker блокируют мёрдж** — не «обсудим после мёрджа».
- Не спорь с тоном — извлеки техническое содержание и отвечай на него.

## Severity-словарь (согласован с review-code-checklist)

| Уровень | Значение | Действие |
|---------|----------|----------|
| critical | Безопасность, потеря данных, прод-падение | Блокирует, фикс до мёрджа |
| blocker | Логическая ошибка, ломает контракт | Блокирует |
| major | Работает, но сломает поддержку/расширение | Фикс до мёрджа или явное решение владельца |
| minor | Стиль, нейминг, мелкая оптимизация | Follow-up допустим |

## Чеклист

- [ ] Дифф без посторонних изменений, <400 строк (или разбит)
- [ ] Контекст + что проверено + зоны риска приложены
- [ ] Каждое замечание получило fixed / follow-up / контраргумент
- [ ] Critical/blocker закрыты ДО мёрджа
